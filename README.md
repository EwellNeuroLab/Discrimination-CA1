# Discrimination-CA1 (The relevance of context in memory tasks influences the magnitude of hippocampal remapping)

The **8port maze** directory contains the inventory, arduino codes and bonsai workflows to build the Discrimin8 maze and implement the discrimination/generalization task.

The **Discrimination 2025 CodeBase** directory contains all the necessary codes to reproduce the analysis and figures presented in the paper.
